# Documentation, Screenshots & Recordings

This directory stores visual assets and media documenting the Artemis application:

### Directories

- **[`screenshots/`](file:///d:/artemis/docs/screenshots/)**: Static images (`.png`, `.jpg`, `.webp`) covering:
  - Startup screen & dynamic greeting
  - Chat interface & markdown / math rendering
  - Model selector popover & brand vendor marks
  - Light and dark themes

- **[`recordings/`](file:///d:/artemis/docs/recordings/)**: Screen recordings & animated previews (`.mp4`, `.webm`, `.gif`) showcasing:
  - Full application walkthrough & startup
  - Real-time streamed responses & thinking animation
  - Voice recording & model switching

### How to Embed Screen Recordings in README.md

#### 1. Animated GIF (Recommended for auto-play across all Markdown viewers)
```markdown
![Artemis Demo](docs/recordings/demo.gif)
```

#### 2. HTML5 Video (MP4 / WebM with playback controls)
```html
<video src="docs/recordings/demo.mp4" controls width="100%"></video>
```
